## Périmètre livré

Exécuteur dataflow sur `GraphSpec` validé (F4) avec journal durable (F3) :

- modes `sequential` et `concurrent` (plafond `maxConcurrency`) ;
- tuyaux bornés `wait` / `reject` / `spill` (jamais de drop silencieux) ;
- commit d’activation avec `invocation_validated` ; reprise sans relance ;
- checkpoint `--checkpoint-after N` (interruption après N commits durables) ;
- délai / annulation observables via événements.
