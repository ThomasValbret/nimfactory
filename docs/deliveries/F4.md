# F4 — Livraison graphe et validation
Date : 2026-11-17  
Périmètre : `src/nimfactory/graph/`, `tests/f4/`, ce reçu  
Dépendances consommées : contrats F0 (`CommonResult`, `HandlerRef`, `FactoryError`, port `GraphValidator`)

## Réalisé

- **GraphSpec** (`nimfactory.graph/0.1`) : nœuds nommés, handlers versionnés, ports typés, arêtes, points d’entrée, sorties, `params`, `loop_specs`, règles de terminaison.
- **Primitives de contrôle** : `sequence`, `branch`, `map`, `join`, `reduce`, `loop`, `subgraph`, `await_event` avec descripteurs JSON ; prédicats `branch` structurés (`equals`, `exists`, `all`, `any`) — refus de `eval`.
- **Join** : politiques `all_required` (défaut), `quorum`, `first_success` ; politiques `on_failure`, `on_late`, `on_cancel`.
- **Registre simulé** : `SimulatedHandlerRegistry` + jeu `registerSeedBasicHandlers` pour l’exemple seed-basic et les tests de contrôle.
- **Validateur** : `validateGraphSpec`, `NimGraphValidator.validate` — schéma, ports, handlers, références, cycles implicites, boucles (`exit` + `max_iterations` + `on_limit`), faisabilité des joins.
- **Codec** : `graphFromJson` / `graphToJson` / prédicats et contrôles associés.

Fichiers principaux :

| Fichier | Rôle |
| --- | --- |
| `src/nimfactory/graph/types.nim` | Types GraphSpec, prédicats, join, boucle |
| `src/nimfactory/graph/codec.nim` | Sérialisation JSON |
| `src/nimfactory/graph/registry.nim` | Registre handlers simulé + ports des primitives |
| `src/nimfactory/graph/validator.nim` | Validation et `NimGraphValidator` |
| `src/nimfactory/graph/graph.nim` | Barrel du module |
| `tests/f4/test_graph.nim` | Tests unitaires F4 |

Exemple :

```nim
import nimfactory/graph/[registry, validator, codec]

let reg = newSimulatedHandlerRegistry()
registerSeedBasicHandlers(reg)
let v = newNimGraphValidator(reg)
let raw = readFile("…")  # JSON GraphSpec
let result = v.validate(parseJson(raw))
```

## Limites

- Pas d’exécution de graphe (F5).
- Compatibilité de schémas de ports : égalité stricte des identifiants `name/version`.
- Sous-graphes : validation de l’existence du graphe enfant non résolue (référence déclarative seulement).
- Détection de cycles : présence d’un cycle de dépendances + exigence de nœud `loop` et `loop_specs` ; pas d’analyse de couvrage fine par arête.
