### Règles structurelles ajoutées en A.1

| Règle | Diagnostic typique |
| --- | --- |
| Chaque port d’entrée **requis** d’un handler ou d’une primitive doit être alimenté par une arête ou un entrypoint | `missing_required_input` |
| Au plus **un** producteur structurel par port d’entrée (arêtes + entrypoints) | `ambiguous_multi_producer` |
| Exception : le port `in` d’un nœud `loop` peut avoir plusieurs producteurs (amorçage + rebouclage corps) | — |
| Toute **composante fortement connexe cyclique** doit contenir un nœud `loop` couvert par un `loop_specs` valide | `dependency_cycle` |
| Les fan-out (une sortie vers plusieurs ports distincts, ex. `map.branch` → plusieurs handlers) restent autorisés | — |
| Fusion structurelle non supportée : ex. `branch.then` et `branch.else` vers le même port consommateur | `ambiguous_multi_producer` |

Exemple :

```nim
import nimfactory/graph/[registry, validator, codec]

let reg = newSimulatedHandlerRegistry()
registerSeedBasicHandlers(reg)
let v = newNimGraphValidator(reg)
let raw = readFile("…")  # JSON GraphSpec
let result = v.validate(parseJson(raw))
```
