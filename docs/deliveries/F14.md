## Réalisé

- **`FileBudgetLedger`** (`src/nimfactory/budget/file_ledger.nim`) implémente le port F0 `BudgetLedger` : `reserve`, `settle`, `markUnknown`, `releaseBeforeSend`.
- Plafonds **imbriqués** sur la chaîne de scope `project/run/prep/task` (préfixes du chemin `/`, p.ex. `proj-1/run-1/prep-1/task-1`).
- Montants en **chaînes d'entiers micro-USD** ; compteur d'**envois max** à chaque niveau.
- **`reserve`** atomique sous verrou processus ; idempotence par `inference_attempt_id` / `attempt_id`.
- **`settle`** à partir d'un reçu d'usage : jetons entrée/sortie/cache optionnels (absence ≠ zéro), `accounting_kind` reported/estimated, `cost_microusd` / `provider_cost_microusd`, `local_resources`, rôle (préparateur/relecteur).
- **`markUnknown`** après émission : réserve conservée, pas de `releaseBeforeSend`.
- **`releaseBeforeSend`** uniquement en état `reserved` + `send_state == not_sent`.
- Tentatives **obsolètes** : le coût est comptabilisé si `settle` est appelé avec `obsolete_attempt`.
- Alias exportés **`SqliteBudgetLedger`** / `openSqliteBudgetLedger` → implémentation fichier (nom historique pour intégrateurs F13).

### Backend transactionnel

**Journal append-only** (`journal.ndjson`) + **snapshot atomique** (`state.json` via écriture `.tmp` puis `moveFile`), répertoire `*.ledger/`.

SQLite via `db_connector` n'est **pas** dans les chemins de compilation imposés (`--path:src` uniquement) et le paquet n'est pas installé dans l'environnement inspecté. Le journal fichier fournit reprise après crash, persistance entre processus et concurrence intra-processus (verrou + opérations sérialisées). Une migration SQLite reste possible sans changer le port.

### Exemple consommateur

```nim
import nimfactory
import nimfactory/budget/budget

let l = openSqliteBudgetLedger("/tmp/run-001.budget")
l.defineScope("proj-1", "1000000", 20)
l.defineScope("proj-1/run-1", "500000", 10)
let r = l.reserve("proj-1/run-1/prep-1/task-1", "inf-attempt-1", 1, "25000")
l.settle(r["reservation_id"].getStr, %*{
  "accounting_kind": "reported",
  "cost_microusd": "12000",
  "input_tokens": 100,
  "output_tokens": 40
})
```
