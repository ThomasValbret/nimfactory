## Réalisé
- `DirectoryArtifactStore` : `put` / `read` / `describe` avec SHA-256, MIME, taille, origines multiples
- Identifiants immuables content-addressed `art-sha256-<hex>`
- Publication atomique (objet en staging puis rename ; manifeste via fichier `.tmp` puis rename)
- Déduplication des octets avec provenances distinctes conservées (champ `origins` + `describe().origin` joint par `|`)
- `LocalSnapshotSource` : `capture` matérialise des fichiers mutables en artefacts ; `resolveSource` / `reproduceInitialRead`
- Types `SourceCaptureRequest`, `SourceSnapshot`, `ReadSet` + JSON helpers (`snapshotToJson`, `readSetToJson`)
- Barrel public `import nimfactory/artifacts`

Exemple consommateur :
```nim
import nimfactory/artifacts

let store = newDirectoryArtifactStore("/tmp/nf-artifacts")
let put = store.put("hello", "text/plain", "demo-origin")
echo store.read(put.id)

let snapSrc = newLocalSnapshotSource(store)
let (snap, rs) = snapSrc.capture(SourceCaptureRequest(
  sources: @[SourceSpec(sourceId: "main", path: "/path/to/file.txt", revisionLabel: "v1")]
))
echo snap.snapshotId, " entries=", rs.entries.len
```
