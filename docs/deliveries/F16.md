## Commandes

```text
nimfactory validate --graph PATH
nimfactory run --graph PATH --store PATH --run-id ID [options]
nimfactory resume --graph PATH --store PATH --run-id ID
nimfactory inspect --store PATH --run-id ID
nimfactory events --store PATH --run-id ID
```

Stdout machine = JSON/NDJSON ; diagnostics humains = stderr.

Codes : 0 ok, 2 invalide, 3 blocked, 4 failed, **5 interrupted**.  
(Le code conceptuel 130 est remplacé par 5 : Nim 2.4 sur cet hôte borne tout exit >127 à 127.)
